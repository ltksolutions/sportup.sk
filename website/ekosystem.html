Platformy · Ekosystém

Tri platformy. Jeden ekosystém.

Národný informačný systém slovenského športu tvorí sústava troch prepojených platforiem. Každá má vlastné API a vlastnú agendu — spoločne pokrývajú celý životný cyklus športu: od registra osôb a organizácií, cez správu klubov, až po podujatia a aktivity.

01 · Platformy

Prehľad platforiem

Každá platforma je samostatný systém s vlastným API rozhraním (MCP), vlastnou databázou a vlastnými certifikovanými aplikáciami. Vzájomná komunikácia prebieha výhradne cez štandardizované API — žiadna platforma nemá priamy prístup do databázy inej.

Aktuálna platforma

SportUp.sk

Centrálny národný register všetkých osôb a organizácií v športe. Eviduje športovcov, trénerov, rozhodcov, delegátov, lekárov, dobrovoľníkov, technický personál aj podporovateľov. Základ celého ekosystému — ostatné platformy sa naň odkazujú.

02 · API architektúra

Komunikácia cez MCP rozhrania

Základom každej komunikácie medzi platformami aj externými aplikáciami sú výhradne štandardizované MCP API rozhrania. Žiadna aplikácia — vrátane interných — nemá priamy prístup k dátam mimo vlastného API. Čítanie aj zápis dát môžu vykonávať len aplikácie certifikované prevádzkovateľom.

Certifikovaný prístup

Každá aplikácia, ktorá chce čítať alebo zapisovať dáta, musí byť certifikovaná prevádzkovateľom príslušnej platformy. Certifikácia zahŕňa schválenie účelu, rozsahu prístupu a bezpečnostný audit. Toto platí aj pre štátne inštitúcie a samosprávy.

03 · Aktéri ekosystému

Kto s ekosystémom pracuje

Ekosystém je navrhnutý pre všetky osoby a organizácie v športe — nie len pre športovcov. Register pokrýva celý rad rolí nevyhnutných pre fungovanie športu a športových podujatí.

OSOBY

Fyzické osoby

Športovci, tréneri, rozhodcovia, delegáti, športoví odborníci, lekári a zdravotný personál, technickí vedúci, dobrovoľníci, podporovatelia, funkcionári.

ORGANIZÁCIE

Právnické osoby

Národné zväzy (90 športov / viac odvetví), kluby, oddiely, mestá a obce, VÚC, komerčné subjekty v športe (hotely, penzióny, cestovné kancelárie), turistické organizácie (OOCR, TIC).

ZAPISOVATELIA DÁT

Zdroje zápisu

Dáta zapisujú viaceré oficálne zdroje: zvazy, kluby, mestá, obce, VÚC, komerčné subjekty — každý v rozsahu svojej kompetencie a certifikácie.

KONZUMENTI DÁT

Odberatelia API

Štát (MŠCRaŠ SR, ÚPVS), výskumné inštitúcie (štatistika, demografia, zdravie), médiá, komerčné aplikácie — všetci výhradne cez certifikované API s explicitným GDPR súhlasom.

04 · Rozsah

90 športov, viacero odvetví

Slovenský šport eviduje 90 uznaných aj neuznaných športov. Niektoré majú viaceré športové odvetvia — napríklad šport Futbal zahŕňa odvetvia Futbal, Futsal a Plážový futbal. Každé odvetvie má vlastný číselník organizácií, súťaží a evidencie osôb.

Okrem uznaných športov systém eviduje aj neuznaných športov a voľnočasových športovcov — pohybové aktivity bez formálnej federatívnej príslušnosti, ktoré sú kľúčové pre rozmer cestovného ruchu a verejného zdravia.

Prepojenie s cestovným ruchom

Platforma Activity.SportUp.sk je priamo prepojená s agendou cestovného ruchu — organizácie OOCR, TIC a komerčné subjekty (hotely, penzióny, cestovné kancelárie) môžu cez certifikované API propagovať a evidovať športové aktivity a podujatia s turistickým presahom.
